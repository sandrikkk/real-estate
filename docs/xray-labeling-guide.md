# X-Ray: როგორ შევაფასო წყვილი (✅ / ❌ / 🤷)

ერთი კითხვა: **ეს ორი განცხადება ერთსა და იმავე ფიზიკურ ბინას ეხება?** (იგივე კორპუსი, იგივე სართული, იგივე კარი.)

- ✅ **იგივეა**: ერთი ბინაა. ფასი, გამყიდველი, თარიღი და ტექსტი შეიძლება განსხვავდებოდეს, ეს ✅-ს არ ცვლის.
- ❌ **სხვაა**: სხვა ბინაა, თუნდაც ძალიან ჰგავდეს: იმავე კორპუსში მეზობელი ბინა იგივე განლაგებით, სხვა სართული, სხვა მიკრორაიონი, ან დეველოპერის ერთი და იგივე რენდერები სხვადასხვა ბინისთვის.
- 🤷 **ვერ ვხვდები**: ნაჩვენები ინფორმაცია არ კმარა (ფოტო არ არის, სართული არ წერია). არასდროს გამოიცნო: როცა არ იცი, 🤷 სწორი პასუხია.

რჩევები:
1. გახსენი ორივე ბმული და შეადარე ფოტოები: ხედი ფანჯრიდან, იატაკი, სამზარეულო, კარი.
2. ფასი მიზეზი არ არის: იგივე ბინა ხშირად სხვა ფასადაა.
3. თუ ერთ წუთზე მეტს ფიქრობ, დააჭირე 🤷.
4. შეცდომით დააჭირე? დააჭირე სწორ ღილაკს: ბოლო პასუხი ითვლება.

რთული შემთხვევები:
- თემქა და ნაძალადევი (2026-11-06): ორივე 1 სართულზე, 62 და 63 მ², მაგრამ 2 ოთახი და 4, 8- და 12-სართულიანი კორპუსი: ❌.
- იგივე კორპუსი, იგივე განლაგება, მე-5 და მე-6 სართული: ❌.
- ერთი ბინა MyHome-ზე $86,000-ად, Facebook-ზე $85,000-ად, იგივე ფოტოებით: ✅.
- ახალი კორპუსის რენდერი, რომელიც 60 განცხადებაშია: ფოტო არაფერს ამტკიცებს, გადაწყვიტე ტექსტით ან 🤷.
- Facebook-ის პოსტი სართულის გარეშე, იგივე ოთახები და ფართი, ფოტო არ ჩანს: 🤷.

**English.** One question: is it the same physical flat? ✅ same flat, whatever the price, seller or date. ❌ a different flat, however alike, including the same-layout neighbour. 🤷 when the shown facts are not enough; never guess. The answers are the exam the weekly X-Ray weights must pass ([ADR 0002](adr/0002-xray-duplicate-match-weights.md)).
